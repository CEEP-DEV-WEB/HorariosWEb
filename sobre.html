Sobre o Sistema de Horário do CEEP Áureo Filho

Tecnologia para facilitar o acesso aos horários escolares.

Sistema de Horários

O Sistema de Horários é uma plataforma desenvolvida para facilitar o acesso dos estudantes aos horários das suas turmas de forma rápida, simples e organizada.

Por meio do sistema, os horários escolares podem ser disponibilizados e atualizados pela instituição, permitindo que os alunos consultem as informações diretamente pela internet utilizando computador, tablet ou celular.

A solução foi desenvolvida pela Almatec e é disponibilizada ao CEEP Áureo de Oliveira Filho por meio de licença de uso.

Desenvolvimento

O sistema é um produto desenvolvido e mantido pela Almatec.

Licença de Uso

O CEEP Áureo de Oliveira Filho possui licença para utilização do sistema no ambiente escolar.

Finalidade

Centralizar e facilitar a consulta dos horários das turmas pelos estudantes.

Como funciona

Um processo simples para manter os horários acessíveis.

1
Atualização

A instituição disponibiliza os arquivos atualizados dos horários escolares.

2
Organização

Os horários são organizados de acordo com modalidade, curso e turma.

3
Consulta

O aluno acessa o sistema e consulta rapidamente o horário da sua turma.
